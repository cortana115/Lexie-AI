# Lexie AI

Law at the Speed of Thought - Lexie is the native AI layer for Microsoft Office.

## Getting Started

This project has been converted from static HTML to Next.js for better development experience and preview support.

### Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

### Build

```bash
pnpm build
pnpm start
```

### Deploy

This project is optimized for deployment on Vercel.

## Project Structure

- `/app` - Next.js app directory with pages and layouts
- `/old-static-site` - Original static HTML files (preserved for reference)

## Tech Stack

- Next.js 16
- React 19.2
- TypeScript
- GSAP for animations
